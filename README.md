# الدفتر اليومي للأستاذ — نسخة Flutter (Android)

هذا مشروع **Flutter** كامل يطابق نفس منطق ووظائف نسخة الويب (HTML) للدفتر اليومي:
الأقسام، التوقيت الأسبوعي (جدول)، التوزيع السنوي، الأسابيع الدراسية، الدفتر اليومي
(مع التأجيل التلقائي بسبب العطل/الاختبارات/الفروض ودمج الأيام المتعددة)، المناسبات
والعطل، الفروض والاختبارات، وتبويب "اليوم"، بالإضافة إلى نسخ احتياطي JSON.

## ⚠️ ملاحظة مهمة

بيئة العمل التي أنشأتُ فيها هذا الكود **لا تحتوي على Flutter SDK** (لا شبكة إنترنت
للتحميل)، لذلك لم أتمكن من تشغيل `flutter analyze` أو بناء APK فعلي هنا. تحققتُ
يدويًا من توازن الأقواس، صحة الاستيرادات، وتوافق واجهات الحزم المستخدمة (بحثتُ عن
`share_plus` تحديدًا للتأكد من صحة الاستخدام)، لكن قد تحتاج لتصحيحات طفيفة عند أول
`flutter pub get` / `flutter run` لديك — هذا متوقع في أي كود لم يُختبر بمترجم حقيقي.

## المتطلبات

- تثبيت [Flutter SDK](https://docs.flutter.dev/get-started/install) (القناة المستقرة).
- Android Studio أو VS Code مع إضافة Flutter.

## خطوات التشغيل

```bash
# 1) داخل مجلد المشروع، ولّد ملفات منصة Android (android/) التي لم تُرفق هنا:
flutter create --platforms=android .

# 2) نزّل الحزم:
flutter pub get

# 3) شغّل على جهاز/محاكي Android:
flutter run

# 4) لبناء ملف APK قابل للتثبيت:
flutter build apk --release
# الملف الناتج: build/app/outputs/flutter-apk/app-release.apk
```

بعد `flutter create --platforms=android .` تأكد أن `android/app/src/main/AndroidManifest.xml`
يحوي `android:label="الدفتر اليومي للأستاذ"` إن أردت تعديل اسم التطبيق المعروض،
وأضف أيقونة التطبيق عبر حزمة `flutter_launcher_icons` إذا رغبت.

## بنية المشروع

```
lib/
  main.dart              — نقطة الدخول + التنقل المتجاوب (Drawer على الجوال، NavigationRail على الشاشات الواسعة)
  theme.dart              — الهوية البصرية (أخضر الختم + ذهبي نحاسي) وشارات Material 3
  models.dart              — نماذج البيانات (Class, ScheduleEntry, CurriculumItem, ...)
  app_state.dart            — الحالة العامة + الحفظ التلقائي (SharedPreferences) + خوارزمية توليد الخطة الأسبوعية
  widgets/slot_tile.dart     — بطاقة حصة واحدة قابلة لإعادة الاستخدام (تُستخدم في "اليوم" و"الدفتر اليومي")
  screens/
    today_screen.dart        — تبويب "اليوم" (بطاقة يوم واحد قابلة للتنقل)
    classes_screen.dart       — الأقسام
    schedule_screen.dart       — التوقيت الأسبوعي (جدول تفاعلي بالدمج)
    curriculum_screen.dart      — التوزيع السنوي
    weeks_screen.dart           — الأسابيع الدراسية
    plan_screen.dart             — الدفتر اليومي الأسبوعي (مع دمج أيام العطل)
    events_screen.dart           — المناسبات والعطل
    tests_screen.dart             — الفروض والاختبارات
    backup_screen.dart             — نسخ احتياطي JSON (نسخ للحافظة / مشاركة / استيراد)
```

## الميزات المضافة مؤخرا

- **استيراد/تصدير التوزيع السنوي**: من تبويب "التوزيع السنوي"، زر "تصدير" يشارك ملف
  JSON يحوي دروس وأعمال موجهة المستوى الحالي، وزر "استيراد" يفتح منتقي ملفات النظام
  (SAF على أندرويد) لاختيار ملف JSON فعلي — لا حاجة للصق النص يدويا.
- **استيراد ملف JSON حقيقي** في تبويب "النسخ الاحتياطي" أيضا (بدل اللصق سابقا) —
  عبر حزمة `file_picker` التي تفتح متصفح الملفات الأصلي لأندرويد.
- **طباعة الدفتر اليومي** من تبويب "الدفتر اليومي" (أيقونة 🖨️ في شريط الأسبوع) —
  يولّد PDF بنفس تصميم نسخة HTML (عنوان الأسبوع أعلى الجدول، 6 أعمدة: التاريخ/
  التوقيت/القسم/سير الحصة/رقم المذكرة/ملاحظات، ودمج المناسبات/العطل الممتدة على
  عدة أيام في شريط واحد)، ثم يفتح واجهة الطباعة الأصلية لأندرويد (طباعة فعلية أو
  حفظ كـ PDF) عبر حزمة `printing`.

## الفروقات المتبقية عن نسخة الويب (تبسيطات متعمدة)

- **استيراد/تصدير التوزيع السنوي والنسخ الاحتياطي** يعتمدان صيغة **JSON** وليس
  Excel (كانت نسخة الويب تستخدم مكتبة SheetJS الخاصة بالويب). يمكن إضافة حزمة
  `excel` أو `syncfusion_flutter_xlsio` لاحقًا إن احتجت Excel حقيقيا.
- الخطوط: تستخدم `google_fonts` (Cairo + Tajawal) وتُحمَّل من الإنترنت عند أول
  تشغيل ثم تُخزَّن محليًا تلقائيًا. طباعة PDF تستخدم خطوط Google Fonts المكافئة
  عبر حزمة `printing` (`PdfGoogleFonts`)، وتُحمَّل أيضا عند أول استخدام للطباعة.

## التصميم

- Material 3 مع نظام ألوان مبني على أخضر "الختم" (`#0E6B4F`) كلون أساسي، وذهبي نحاسي
  للأرقام (رقم المقطع، رقم المذكرة، التوقيت).
- تنقّل متجاوب: قائمة جانبية (Drawer) على الشاشات الضيقة، وشريط تنقّل جانبي دائم
  (NavigationRail) موسّع تلقائيًا على الشاشات العريضة (تابلت/سطح مكتب Flutter Web إن رغبت).
- محرر التوقيت الأسبوعي يفتح كـ Bottom Sheet (يظهر دائمًا فوق الشاشة المرئية، حلاً
  للمشكلة التي واجهناها في نسخة الويب حيث كان النموذج يظهر خارج حدود الشاشة).
